# Web Engineering Lab 01

This project was created for Web Engineering Lab 01.

## Features

- HTML page structure
- CSS styling
- JavaScript greeting function
- Automated test using Node.js built-in test runner
- ESLint and Prettier development tools

## Commands

- `npm start` — starts the local web server
- `npm test` — runs the automated tests
- `npm run lint` — checks JavaScript files
- `npm run format` — checks formatting
